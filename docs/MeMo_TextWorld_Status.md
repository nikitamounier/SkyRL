## 1. Architecture

```
TextWorld Game (50 turns per episode)
  |
  | every `memory_window` turns (e.g. 5)
  v
Memory Documents (text summaries: "Turn 1-5: went north, took key, opened box...")
  |
  | Qwen3-Embedding-4B via SentenceTransformer (on CPU)
  v
Document Embeddings [num_docs, 2560]    (one 2560-dim vector per document)
  |
  | Memory Module: 1-layer transformer encoder + cross-attention
  | 8 learned query vectors attend over num_docs document embeddings
  v
8 Memory Token Embeddings [8, 2560]
  |
  | Replace <|image_pad|> placeholder tokens in system message
  v
Qwen3-4B-Instruct (frozen LLM) sees: [text embeddings ... memory embeddings ... text embeddings]
  |
  | Causal LM generates action
  v
"[ACTION: go north]" --> TextWorld environment steps
```

**Two training approaches**:
- **RL (SkyRL/GRPO/REINFORCE++)**: Only Memory module trained via policy gradient. Sparse reward (win/lose). **Result: failed** -- base model can't play, rewards trend down.
- **SFT (MeMo trainer)**: Memory module trained via cross-entropy on expert actions. Dense signal per token. **Result: in progress** -- generating GPT-5-mini expert data.

## 2. TextWorld Games

**What**: Text-based adventure puzzles generated by Microsoft's TextWorld framework. Player navigates rooms, picks up items, unlocks containers, completes objectives.

**Game structure**:
- 15-40 rooms connected by N/S/E/W exits
- 12-35 objects (keys, containers, items on surfaces)
- Objective: sequence of 6-16 steps printed ONCE in the first observation
- Binary scoring: 1 if all objectives complete, 0 otherwise

**Valid commands**: `go north/south/east/west`, `take <item>`, `drop <item>`, `open <container>`, `close <container>`, `examine <object>`, `unlock <thing> with <key>`, `lock <thing> with <key>`, `put <item> on <surface>`, `insert <item> into <container>`, `inventory`, `look`

**Difficulty mix** (in our dataset):
- Medium (30%): 15-25 rooms, 6-10 quest steps
- Hard (70%): 24-40 rooms, 10-16 quest steps

**Game files**: 400 games at `/home/parsaidp/data/textworld_memo/games_v2/`
- `.z8` (playable binary), `.json` (metadata), `.ni` (Inform 7 source)

## 3. Results & Findings

### Eval Baselines (no training, no memory)

| Model | Prompt | Test (20) | Validation (40) | Train (340) |
|-------|--------|-----------|-----------------|-------------|
| Qwen3-4B | Old minimal | 4/20 (20%) | 16/40 (40%) | 90/340 (26.5%) |
| Qwen3-4B | New w/ commands | 5/20 (25%) | 20/40 (50%) | -- |
| **GPT-5-mini** | **New w/ commands** | **15/20 (75%)** | **~85% est.** | **~89% (generating)** |

### Key Finding
Qwen3-4B spams `[ACTION: move south]` (wrong syntax -- TextWorld needs `go south`) for 50 turns straight. It doesn't understand TextWorld commands or follow objectives. GPT-5-mini reasons step-by-step and solves games in 8-14 turns. **Memory can't fix a model that doesn't know how to play.**

### RL Training Results (20 runs, Feb 8-9)

**All runs trend DOWN over 50+ steps.** The small-init (std=0.01) fixed gradient flow (no more nan), but the memory module learns to produce outputs that hurt rather than help.

Best configs found (for future use after SFT):
- **GRPO + w3**: Fast initial improvement, but unstable with larger windows
- **REINFORCE++ + w10**: Most stable, slow convergence
- **LR=1e-4**: Sweet spot. 5e-4 explodes, 5e-5 too slow
- **n_samples=5**: 8 doesn't help. **t50 turns**: 100 doesn't help.

## 4. What Was Tried

### Changes Made (chronological, Feb 7-9)
1. **Embedding model swap**: LLM `embed_tokens` (raw lookup) --> `Qwen3-Embedding-4B` (semantic). Matches MeMo reference.
2. **Multi-doc bundling fix**: Was passing [1,1,2560] per doc (cross-attention useless). Fixed to [1,num_docs,2560] (all docs in one batch).
3. **Initialization saga**:
   - Xavier random --> gradient explosion (loss=105K, grad_norm=18M on step 1)
   - Zero init --> no learning at all (grad=nan for 9 hours -- backward skipped because loss has no grad_fn)
   - **Small init (std=0.01)** --> gradients flow, but rewards still trend down
4. **Reward shaping**: `step_penalty=0.01` + `efficiency_bonus=1.0`. Gives dense signal but doesn't overcome broken base policy.
5. **Speed fixes**: `max_model_len` 262K-->4224 (22x vLLM concurrency), `max_prompt_length` 16K-->4K, `max_generate_length` 256-->128.
6. **System prompts**: Updated with valid TextWorld commands + strategy tips. Bumped Qwen3-4B from 20%-->25%.
7. **OpenAI SFT pipeline**: Parallel GPT-5-mini gameplay for expert data generation.

### Root Cause Analysis
RL training from scratch fundamentally limited by:
1. Base model can't play (wrong commands, no reasoning, no objective tracking)
2. Memory can't compensate for broken base policy
3. Sparse reward (win/lose) + gradient instability = no stable learning signal
4. Memory outputs small perturbations that periodically destabilize the frozen LLM

## 6. Data Formats

### RL Training Dataset (parquet)
Used by SkyRL trainer. Each row = one game to play interactively.
```python
{"prompt": [{"role": "system", ...}, {"role": "user", ...}],
 "env_class": "textworld",
 "game_file": "/path/to/game.z8",
 "modalities": {...}}
```
680 rows = 340 games x 2 prompt variants.

### GPT-5-mini Transcripts (JSON per game)
Generated by `play_textworld_openai.py`. Full gameplay recording.
```python
{"game_id": "game_00094_medium_...",
 "model": "gpt-5-mini",
 "won": true, "final_score": 1, "num_turns": 6, "sample_id": 0,
 "turns": [{"turn": 1, "observation": "...", "action": "go south",
            "model_response": "I'll head south...\n[ACTION: go south]",
            "reward": 0.0, "score": 0, "done": false}, ...],
 "messages": [{"role": "system", ...}, {"role": "user", ...}, {"role": "assistant", ...}, ...]}
```

### MeMo SFT Format (per-turn)
Created by `prepare_textworld_sft.py`. Each example = one turn with memory context.
```python
{"prompt": [system_msg, ...recent_turns, current_obs],
 "response": "expert action",
 "memory_documents": ["Turns 1-5 summary...", "Turns 6-10 summary..."],
 "game_id": "...", "turn": 6, "num_memory_docs": 2}
```
Memory documents saved as `.txt` files, embedded with Qwen3-Embedding-4B at training time.

## 8. How to Run

### Generate expert gameplay data
```bash
export OPENAI_API_KEY="sk-..."
python skyrl-train/examples/MeMo/play_textworld_openai.py \
    --data_file ~/data/textworld_memo/train.parquet \
    --model gpt-5-mini --n_samples 3 --workers 16 --skip_existing \
    --output_dir /large_storage/goodarzilab/parsaidp/MeMo/data/sft_gpt5mini_train
```

### Convert transcripts to MeMo SFT format
```bash
python /home/parsaidp/MeMo/prepare_textworld_sft.py \
    --transcript_dir /large_storage/.../sft_gpt5mini_train \
    --output_dir /large_storage/.../memo_sft_train \
    --memory_window 5 --context_turns 3
```

### Run baseline eval (no memory)
```bash
sbatch eval_textworld_baseline.slurm                                          # test set
DATA_FILE=~/data/textworld_memo/validation.parquet sbatch eval_textworld_baseline.slurm  # val set
```

### Submit RL training run
```bash
ADVANTAGE_ESTIMATOR=grpo LR=1e-4 MEMORY_WINDOW=5 \
    STEP_PENALTY=0.01 EFFICIENCY_BONUS=1.0 \
    RUN_NAME=my_run CKPT_DIR=/path/to/ckpts \
    sbatch -p preemptible train_textworld_memo.slurm
```

### Submit training sweep
```bash
bash launch_comparison.sh                          # GRPO vs REINFORCE++ x w3/w5/w10
PARTITION=gpu bash launch_comparison.sh            # on gpu partition
```

### Regenerate RL dataset with new prompts
```bash
DATA_DIR=/large_storage/.../textworld_memo_v3 GAMES_DIR=~/data/textworld_memo/games_v2 \
    sbatch prepare_textworld_data.slurm
```

## 10. Known Pitfalls

1. **vLLM max_model_len**: Defaults to 262K (full Qwen3 context). MUST override to ~4224 or inference is 10x slower with 1.39x concurrency instead of 22x.
2. **Memory projection init**: Xavier random = gradient explosion (18M grad norm). Zero = no learning (grad=nan, backward skipped). Use `std=0.01`.
3. **Warmup steps bug**: `num_warmup_steps` in SkyRL counts optimizer steps not training steps. Setting to 2 keeps LR at 0 forever. Don't use -- small-init is sufficient.
4. **SLURM --wrap**: Uses `/bin/sh` not bash. Use `. activate` not `source activate`.
5. **GPT-5-mini API**: Only supports `temperature=1.0` and `max_completion_tokens` (not `max_tokens`).
6. **TextWorld thread safety**: `textworld.start()` is not thread-safe. Wrap in threading.Lock.
7. **Payload format**: Env sends raw text strings (list of strings bundled as one payload), NOT token_ids. Must match `MemoSentenceEmbeddingEncoder`.
8. **Multi-doc bundling**: All docs for a game = ONE payload (list of strings). NOT separate payloads. Otherwise cross-attention gets [1,1,2560] (useless) instead of [1,N,2560].
9. **System prompts matter**: Without listing valid TextWorld commands, Qwen3-4B outputs `move south` (invalid). With commands listed, it outputs `go south` (valid).
10. **Slurm memory**: 64G is not enough for w3/w5 (OOM at ~67G). Use 96G.
